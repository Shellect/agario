# Задания блока

Сдача: каталог `common/` в их репозитории плюс точечный diff `server/`. Сеть не обязана играть до задания 6.

## Задание 1 (после пары 1). Карта владения

Письменно, на одну страницу, по файлам `tcp_session.h/.cpp` и `udp_server.h/.cpp`.

Для полей `sock_`, `udp_`, `hdr_`, `body_`, `clients_`, `sender_`, `m_` ответить тремя словами: кто владеет, кто только смотрит, когда объект перестаёт быть нужен.

Отдельно: компилируется ли `TcpSession b = a` и почему это плохо для сокета.

Критерий: ссылка `UdpServer&` названа невладеющей; `shared_ptr` из `shared_from_this` назван тем, кто держит сессию до конца колбэка.

## Задание 2 (пары 2–4). Игрок и еда

Перенести в `common/` файлы из `materials/code/`: `vector2d.hpp`, `entity.hpp`, `player.hpp`, `food.hpp`.

Дописать программу `sandbox/slice.cpp` (в зачёт не идёт игра):

- контейнер `std::vector<std::unique_ptr<Entity>>` с одним `Player` и одной `Food`;
- вызов `update` и `radius()` через базу;
- комментарий на 5–8 строк, почему `std::vector<Entity>` здесь не подходит.

Критерий: деструктор базы виртуальный, методы наследника помечены `override`, копирование `Player` студенту не нужно запрещать (это значение с числами).

## Задание 3 (пары 5–6). Мир и Catch2

Подключить `world.hpp`. Тесты, без сокетов:

1. Две еды далеко от игрока — после `tick` в мире 3 сущности.
2. Еда в той же точке, что игрок — после `tick` еды нет, радиус игрока больше стартового.
3. Пустой мир: `size() == 0`, `tick` не падает.

Не тестировать `dynamic_cast` как самоцель. Тестировать наблюдаемый результат: сколько объектов и какой радиус.

## Задание 4 (пара 7). Сессию нельзя скопировать

В `TcpSession` удалить копирование и перемещение. Сборка проекта должна остаться зелёной. Если где-то сессия лежала в контейнере по значению — заменить на `std::shared_ptr<TcpSession>`.

Короткий комментарий в заголовке: почему move тоже удалён.

## Задание 5 (пара 8). Ответ на join без синхронного write

В ветке входного сообщения (`MSG_JOIN` / тип из `protocol`, не «магическая единица»):

- не отправлять неинициализированный `uint8_t out[4]`;
- не вызывать блокирующий `net::write` из колбэка чтения;
- буфер ответа должен пережить возврат из лямбды (поле сессии или `shared_ptr`);
- захват колбэка записи — копия `shared_ptr` на сессию, как в `doReadHeader`.

Проверка: клиент `nc` или маленький `main` подключается, шлёт заголовок join и не роняет сервер. Под ASan/Clang — нет use-after-free. На MSVC без санитайзера достаточно ревью захвата.

## Задание 6 (пара 9). Общий протокол

Заменить разрозненные `type == 1` на `protocol::TcpMsgType`. Реализовать в `common`:

- сборка пакета `Input` (заголовок 3 байта + два `float`);
- чтение только если `body.size() >= 8`;
- неверная длина не приводит к `memcpy` за границей.

Клиент: отправка одного `Input` после подключения. Окно SFML — по желанию, на оценку не влияет. Оценка за совпадение байтов с тем, что читает сервер.

Чужой PR или папка. Отметить да/нет по чеклисту из конспекта пары 10. Один найденный дефект — с файлом и строкой, без переписывания чужого проекта целиком.
